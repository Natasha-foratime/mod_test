# Итоговая работа: Автотестирование сайта SauceDemo

## Описание проекта
Данный репозиторий содержит выполнение итоговой работы по написанию автотестов на Selenium.

**Важное примечание:** Исходный файл `docker-compose.yml` с сайтом OpenCart, выданный в задании, не работал, поэтому в качестве альтернативы для выполнения задания был выбран учебный сайт SauceDemo (Swag Labs), который специально создан для практики автотестирования.

## Как запустить сайт локально
1. Установите Docker Desktop.
2. Скачайте файл `docker-compose.yml` из этого репозитория.
3. Откройте терминал в папке с файлом и выполните команду:
   ```bash
   docker compose up -d
